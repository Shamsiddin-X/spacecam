# Initial scene images

These unmodified images are bundled so the opening scene does not depend on third-party image requests. Downloaded on 2026-11-15. Detailed HiPS tiles and other wavelength channels still load from the archives.

- `spherex-allsky.png`: SPHEREx DR1, first infrared channel (0.753 µm), NASA/IPAC IRSA HiPS node: https://irsa.ipac.caltech.edu/data/hips/SPHEREx/spherex_allsky_cube/Norder3/Allsky.png
- `earth-day.jpg`: NASA Blue Marble texture, from the three-globe example used by this project: https://unpkg.com/three-globe/example/img/earth-blue-marble.jpg
- `earth-night.jpg`: Earth at night texture, from the same example: https://unpkg.com/three-globe/example/img/earth-night.jpg

Data credit: NASA/JPL-Caltech/IPAC (SPHEREx), NASA Visible Earth (Earth textures). These are source imagery, not AI-generated visuals. See the site credits for the full SPHEREx acknowledgement.
