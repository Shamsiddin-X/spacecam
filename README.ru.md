# SpaceCam

Открытый инструмент для исследования инфракрасного неба NASA SPHEREx: 3D-Земля, обзорные карты, сравнение эпох, отслеживание движения и поиск кандидатов на изменения.

[English README](README.md) · [MIT](LICENSE) · [Инструкция по публикации](docs/DEPLOYMENT.md)

## Локальный запуск

Нужен Node.js 22.x:

```bash
npm ci
npm run dev
```

Открой [localhost:3000](http://localhost:3000). Для загрузки данных из архивов нужен интернет.

```bash
npm test
npm run build
```

## Публикация на Vercel

1. Импортируй репозиторий `Shamsiddin-X/spacecam` в Vercel.
2. Оставь Root Directory в корне репозитория, выбери Framework Preset **Other**.
3. Сборка: `npm run build`; папка результата: `dist`; Node.js: **22.x**.
4. Нажми Deploy. Переменные окружения и ключи API не требуются.

Встроенный `/api/proxy` обеспечивает доступ к публичным данным NASA IRSA/JPL. Отдельно настраивать Cloudflare для Vercel не нужно. Архивы могут отвечать медленно или не содержать снимков для выбранной точки.

Готовые поля примеров не включены в репозиторий: сайт загружает данные по запросу. Необязательный Python-конвейер позволяет подготовить поля заранее; команды и ограничения описаны в [основном README](README.md#data-and-optional-python-tools).
